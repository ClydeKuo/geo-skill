# 通用检查清单

适用于所有市场。凡是写"见市场档案第 N 节"的地方，读取目标市场的 `markets/<代码>.md`；未建档市场读 `markets/_generic.md`。每一项都标注了证据编号（见 `evidence.md`）。目标市场不是 `us` 时，建议一律加"（推断）"，除非该市场档案第 8 节写明有直接证据。

## 优先级规则

- **P0 阻断**
  - 检索类或用户触发类 AI 爬虫被 robots.txt 明确拦截（全球通用爬虫，或目标市场档案第 4 节列出的本地爬虫）
  - 核心页面不执行 JS 时的正文比例 < 50%
  - 首页不是 200（被审计机遭 WAF 挑战时为 `unknown`，不算 P0）
  - 目标国家可访问性：有该国出口代理时测得打不开
- **P1 高**
  - 核心问题没有页面直接回答
  - 重点页缺少可核实的证据单元
  - 站外几乎没有第三方提及
  - 伪装 AI UA 被 WAF 拦截（`suspect`，需客户核对）
  - 页面 canonical 指向其他地址或会跳转的地址
  - 目标市场没有当地语言版本，或只有机器翻译
  - hreflang 指向的语言版本打不开或会跳转
- **P2 中**
  - 标题层级混乱
  - 缺更新时间或作者
  - description 与搜索意图不符
  - 结构化数据缺失（注明"证据弱，作为卫生项"）
  - hreflang 缺失或不双向
- **不判优先级**
  - 没有目标国家出口代理时，可达性标"未检测（无该国出口）"
  - 训练类爬虫被拦：只说明利弊，由客户决定

## 第1层 可抓取（脚本：`crawl_check.py`、`render_diff.py`）

- [ ] 首页状态码与响应时间（`homepage`）：非 200 → P0；`unknown`（被挑战）→ 说明审计受限；> 3 秒 → P2。依据 E2。
- [ ] robots.txt 能否读取（`robots.value.source`）：`unreachable` → 所有爬虫结论为"未能检测"，说明原因。依据 E2。
- [ ] 全球通用的检索类与用户触发类爬虫是否放行（`ai_crawlers` 中 `markets` 含 `all` 且 purpose 为 search/user 的项）：被拦 → P0。依据 E2。
- [ ] 目标市场的本地爬虫是否放行（见市场档案第 4 节；`ai_crawlers` 中 `relevant` 为 true 的本地项）：检索类被拦 → P0。依据 E2。
- [ ] 训练类爬虫是否放行：被拦 → 只说明利弊，由客户决定。依据 E12。
- [ ] WAF / CDN 是否拦截 AI UA（`ua_blocking`）：`suspect` → P1；`warn` → 说明审计受限；`unknown`（被限流或请求失败）→ 写"未能检测"。依据 E2、E11。
- [ ] 不执行 JS 时的正文比例（`render_diff.py` 的 `ratio`），每个目标市场的语言版本都要测：< 0.5 → P0；0.5–0.8 → P1；列出 `js_only_headings`。依据 E11。
- [ ] meta robots / X-Robots-Tag 是否含 noindex：重点页含 noindex → P0。依据 E2。
- [ ] sitemap 是否存在、是否覆盖重点页（`sitemap.value.truncated` 为 true 时注明未读完）：缺失 → P2。依据 E2。
- [ ] 每个重点页的 canonical（`page_audit` 的 `canonical`）：指向其他地址或跳转地址 → P1。依据 E2。
- [ ] HTTPS：否 → P2。依据 E2。
- [ ] 目标国家可达性：有该国出口代理时用 `--proxy` 测试，打不开 → P0；没有 → "未检测（无该国出口）"。依据 E2。
- [ ] llms.txt：只记录有无，放进"不建议投入"一节。依据 E10。

## 网站多语言版本（脚本：`crawl_check.py` 的 `hreflang`，`page_audit.py` 的 `hreflang`）

- [ ] 是否声明 hreflang（HTML、HTTP Link 头、sitemap 任一来源；`hreflang.check`）：全无 → P2。依据 E13。
- [ ] 每个语言版本是否可访问（`hreflang.alternates` 中 `fail`）→ P1；是否回链首页（`warn`）→ P2。依据 E13。
- [ ] 是否有 `x-default`；`<html lang>` 是否与该版本的 hreflang 一致。依据 E13。
- [ ] 每个目标市场是否有当地语言版本：没有 → P1。依据 E1、E13。
- [ ] 当地语言版本是否为人工本地化（阅读正文：术语是否地道、有无直译痕迹、是否残留其他语言）：明显机翻 → P1。依据 E1、E13。
- [ ] 本地化要点（见市场档案第 7 节：货币、日期、单位、联系方式、法律页面）：缺失 → P2。依据 E4、E13。

## 第2层 可检索（agent 判断）

- [ ] 每个目标市场用当地语言推演 10–20 个问题，句式参考市场档案第 6 节，覆盖认知 / 对比 / 决策 / 售后四个阶段。依据 E1、E15。
- [ ] 每个问题：该市场语言版本中是否有页面的 title 或 H2/H3 直接对应，是否有一段话直接给出答案。核心问题无覆盖 → P1。依据 E1。
- [ ] title 与 meta description 是否用当地用户的问法，而不是品牌口号或直译。依据 E1。
- [ ] 是否有对比页、价格页、规格页、售后 / 故障排查页。依据 E1、E4、E12。

## 第3层 可吸收（脚本：`page_audit.py` + 阅读 `--save-html` 保存的正文）

- [ ] 重点页是否包含可核实的数据（`numbers`）、日期（`dates`）、外部引用（`external_links`）、引语（`blockquotes`）：几乎为零 → P1。依据 E3、E16。
- [ ] 是否有明确的定义句、对比表（`tables`）、操作步骤。依据 E3。
- [ ] 价格、规格、更新日期是否为页面上的明文（不只在图片、长图或 JS 数据里）。依据 E4、E11。
- [ ] 隐藏正文：折叠的 FAQ 答案只在 JS 数据里、数字动画在 HTML 中显示为 0 等。发现了 → P1。依据 E11。
- [ ] 标题层级：H1 恰好 1 个、无跳级（`h1_count`、`heading_skips`）；不符合 → P2。依据 E5。
- [ ] 是否一段只讲一个主张、每段可以单独被引用。依据 E3、E5。
- [ ] 作者与更新时间（`author`、`date_modified`）：缺失 → P2（卫生项）。依据 E9。
- [ ] 结构化数据（`jsonld_types`）：缺失 → P2（卫生项，证据弱）。依据 E9。
- [ ] 有没有关键词堆砌、空洞的宣传语（"行业领先""No.1"等无依据的说法）：有 → 建议改为可核实的事实。依据 E7、E8。

## 第4层 站外提及（用网页搜索工具，平台见市场档案第 5 节）

- [ ] 当地语言百科是否有品牌或产品词条，或在相关词条中被提及。依据 E12。
- [ ] 当地问答社区、论坛中是否有真实讨论。依据 E12。
- [ ] 当地评测媒体、榜单文章中是否出现。依据 E12。
- [ ] 当地电商与点评平台上的评价（视行业）。依据 E12。
- [ ] 几乎没有第三方提及 → P1，给出可执行的 PR / 评测 / 榜单策略（不得建议刷评或伪造评价）。依据 E12。
- [ ] 需要登录才能查看的平台、当前环境没有网页搜索工具时，写"未能检测"及原因。依据 E15。
