# 国内市场检查清单

目标引擎：豆包、DeepSeek、Kimi、腾讯元宝、文心一言 / 百度 AI 搜索、通义千问 / 夸克。

**本清单的建议属于"推断，证据较弱"**：学术研究几乎都在英文 / 美国市场做，这里按相同机制（先被检索、再被采纳）类推。报告中引用时要写明。

P0/P1/P2 规则与海外清单相同，另加两条：

- 国内网络可达性：审计机没有中国大陆出口时，标为"未检测（无大陆出口）"，提醒人工核实，**不列 P0**。
- 伪装 AI UA 被 WAF 拦截（`suspect`）→ P1，需客户核对。

## 第1层 可抓取（脚本：`crawl_check.py`、`render_diff.py`）

- [ ] 国内网络可达性：有大陆出口时用 `--proxy` 测试，打不开 → P0；没有大陆出口 → "未检测"。依据 E2。
- [ ] robots.txt 对国内检索类爬虫（Baiduspider、Sogou web spider、YisouSpider、360Spider、PetalBot）的放行：被拦 → P0。依据 E2。
- [ ] Bytespider 是否放行：属于训练类，被拦时与其他训练爬虫一样只说明利弊、由客户决定，不列为问题；说明中要提到它可能影响豆包与头条搜索的收录（推断）。依据 E12。
- [ ] WAF / CDN 是否拦截国内爬虫 UA（`ua_blocking`）：`suspect` → P1。依据 E2。
- [ ] 不执行 JS 时的正文比例：< 0.5 → P0。百度爬虫对 JS 的支持有限，国内 AI 爬虫的情况未公开，按"不执行 JS"保守处理。依据 E11。
- [ ] meta robots / X-Robots-Tag 是否含 noindex（包括 `baiduspider` 专用的 meta）。依据 E2。
- [ ] sitemap 是否存在（百度站长平台可提交）。依据 E2。
- [ ] ICP 备案号是否展示（`icp`）：未展示 → P2，说明可能影响国内平台的信任和收录（推断）。依据 E12。

## 第2层 可检索（agent 判断）

- [ ] 推演 10–20 个中文用户问题，覆盖认知 / 对比 / 决策 / 售后四个阶段，包括"X 哪个牌子好""X 和 Y 有什么区别""X 多少钱""X 怎么选"等口语句式。依据 E1、E15。
- [ ] 每个问题：站内是否有页面的标题或小标题直接对应，是否有一段话直接给出答案。核心问题无覆盖 → P1。依据 E1。
- [ ] 中文内容是否为简体、本地化（单位、价格用人民币、本地案例），不是英文站的机翻。依据 E13。
- [ ] title / description 是否使用中文用户的问法。依据 E1。

## 第3层 可吸收（脚本：`page_audit.py` + agent 阅读正文）

- [ ] 重点页是否包含可核实的数据、日期、权威出处（国家标准号、检测报告、监管部门数据）、引语：几乎为零 → P1。依据 E3、E16。
- [ ] 是否有定义句、对比表、操作步骤。依据 E3。
- [ ] 价格、规格、更新日期是否为明文，不只在图片或长图里（国内站常见整页长图）。依据 E4、E11。
- [ ] 标题层级：H1 恰好 1 个、无跳级 → 否则 P2。依据 E5。
- [ ] 作者、更新时间、结构化数据：缺失 → P2（卫生项）。依据 E9。
- [ ] 有没有关键词堆砌、空洞的宣传语（"行业领先""全网第一"等无依据的说法）：有 → 建议改为可核实的事实。依据 E7、E8。

## 第4层 站外提及（agent 用 WebSearch / WebFetch，查不到标"未能检测"）

- [ ] 百度百科是否有品牌词条。依据 E12。
- [ ] 知乎问答、专栏中是否有真实讨论或测评。依据 E12。
- [ ] 百家号、今日头条、微信公众号文章中的报道。依据 E12、E13。
- [ ] 小红书笔记、什么值得买等消费平台（视行业）。依据 E12。
- [ ] 行业垂直媒体、榜单文章（"十大品牌"类）。依据 E12。
- [ ] 几乎没有第三方提及 → P1，给出可执行的 PR / 测评 / 内容投放策略（不得建议刷评或伪造测评）。依据 E12。
- [ ] 需要登录才能查看的平台不在检测范围内，在报告中注明。依据 E15。
