## 2. 主流 AI 助手与 AI 搜索

各家公布的口径不同（独立 App 月活和"内嵌在大 App 里的助手"月活不能直接比较），下面的顺序只是大致的规模顺序。

| 产品 | 运营方 | 规模（口径） | 联网检索 | 依赖的搜索来源（已知时） |
|---|---|---|---|---|
| 豆包 | 字节跳动 | 2026 年 9 月 AI 原生 App 月活第 1，约 4.19 亿（QuestMobile）[2] | 是 | 字节自有的"豆包搜索"，官方称融合全网信息与"字节跳动独家内容资源"，并按站点和创作者两个维度给信源做权威分级 [9]；实测用户侧高频引用今日头条、抖音，TOP5 信源中 3 个来自字节系 [8] |
| 千问（原通义 App）/ 夸克 | 阿里巴巴 | 千问 2026 年 9 月月活约 1.58 亿，排第 2 [2] | 是 | 未查到阿里公开说明千问联网检索用的是哪套索引。千问 App 于 2025-11-17 公测，全面替代通义 App；夸克作为 AI 搜索 / 浏览器继续独立运营 [4] |
| 文心助手 / 百度 AI 搜索 | 百度 | 百度称百度 App 内的文心助手月活超 2 亿，百度 App 月活超 7 亿（百度口径，含 App 内入口）[3] | 是 | 依托文心大模型和"百度猎户座"AI 引擎，以"搜索 + AI"方式嵌在百度 App 中 [3]，即依赖百度搜索本身 |
| DeepSeek | 深度求索 | 2026 年 9 月月活约 1.23 亿，排第 3 [2] | 是 | 2025 年 3 月报道称其联网搜索由博查（Bocha）Search API 提供 [6]；未查到 2026 年的更新说明。实测偏好搜狐、百度百科、网易 [8] |
| 腾讯元宝 | 腾讯 | 2026 年 9 月月活约 3733 万，排第 4 [2] | 是 | 联网搜索覆盖微信公众号、视频号等腾讯生态内容及外部网站 [15]；实测用户侧微信公众号信源占比约 10% [8]。腾讯另于 2026-11-11 上线独立的"元宝搜索"（千亿级网页索引，接入公众号、视频号、腾讯新闻）[7]，但未查到它与元宝 App 联网检索的关系 |
| Kimi | 月之暗面 | 2025 年四季度月活约 902.7 万，较一季度的 2165.3 万下降 58.3%（QuestMobile）[5] | 是 | 未查到公开的搜索合作方；实测常引用微信公众平台、搜狐 [8] |

要点：

- 豆包、千问、DeepSeek、元宝是 2026 年 QuestMobile AI 原生 App 月活前四 [1][2]；QuestMobile 一季度报告明确提出"GEO 并非一刀切的通用策略"，各平台用户画像不同，信源偏好也不同 [1]。
- 有大厂背景的 AI 主要依赖自家内容生态（豆包—头条 / 抖音，元宝—公众号），DeepSeek、Kimi 的信源较分散 [8]。
- 同一家的 API 与 App 用户侧引用的信源差异很大（豆包 API 很少用头条 / 抖音，元宝 API 很少用公众号），实测应以 App 用户侧问答为准 [8]。

## 3. 搜索引擎与 AI 的关系

**搜索引擎份额**（StatCounter，2026 年 10 月，全平台）[10]：百度 49%、Bing 21.69%、Yandex 11.77%、好搜（360）8.67%、Google 6.83%、搜狗 1.72%。

口径提醒：StatCounter 按装有其统计代码的网站的访问来源统计，统计不到 App 内搜索（微信搜一搜、抖音搜索、小红书搜索等）；Google 在大陆无法正常访问，其份额和 Yandex 的比例都应谨慎看待（这是对口径的判断，非来源结论）。结论只用到"百度是网页搜索的第一入口"这一层。

**AI 与搜索索引的对应**：

- 文心助手 = 百度搜索 + 文心大模型 [3]。被百度收录是文心可见的前提。
- 豆包 = 字节自有搜索（豆包搜索）+ 字节独家内容 [9]。
- 元宝 = 腾讯生态（公众号、视频号）+ 外部网站 [15]；元宝搜索有独立的网页索引 [7]。
- DeepSeek = 第三方搜索 API（2025 年为博查）[6]。博查称承接国内 AI 应用约 60% 的联网搜索请求（2025 年 3 月，厂商自述）[6]。
- 千问 / 夸克、Kimi：未查到公开的索引来源。

**本地特有的 AI 搜索功能**：

- 百度 App 内的文心助手（"搜索 + AI"）[3]。
- 元宝搜索结果页顶部的"AI 总结"与可连续追问的"AI 模式"，并按"公众号""主流媒体""组织机构"等频道区分信源，官方网站会被明确标识 [7]。
- 夸克定位为 AI 搜索 / 浏览器，与千问 App 并行 [4]。

## 4. 本地爬虫

robots.txt 中需要检查的国内爬虫：

- `Baiduspider`（百度搜索 / 文心）：搜索检索类，被拦 → P0。另查 meta robots 中针对百度的专用写法（name 为 baiduspider 的 meta）是否含 noindex。
- `Sogou web spider`（搜狗，腾讯）：搜索检索类，被拦 → P0。元宝没有公开的独立爬虫 UA，搜狗放行情况可作为腾讯生态可见度的间接参考（推断）。
- `YisouSpider`（神马 / 夸克，阿里）：搜索检索类，被拦 → P0。
- `360Spider`（360 搜索）：搜索检索类，被拦 → P0。
- `PetalBot`（华为花瓣搜索 / 小艺）：搜索检索类，被拦 → P0。
- `Bytespider`（字节跳动）：登记为训练类，被拦时只说明利弊、由客户决定，不列为问题；说明中要提到可能影响豆包与字节系搜索的收录（推断）。

DeepSeek、Kimi、元宝没有公开的爬虫 UA，它们的可见度只能通过"能否被其搜索来源收录"间接判断，报告中标"推断，证据较弱"。

其他从原国内清单迁移的抓取层规则：

- 国内网络可达性：审计机有大陆出口时用代理测试，打不开 → P0；没有大陆出口时标"未检测（无大陆出口）"，提醒人工核实，不列 P0。
- 伪装国内爬虫 UA 被 WAF / CDN 拦截（结果为 suspect）→ P1，请客户核对 CDN 设置或服务器日志。
- 国内 AI 爬虫是否执行 JS 未公开，按"不执行 JS"保守处理：不执行 JS 时正文比例 < 0.5 → P0。
- sitemap 是否存在，提醒客户向百度搜索资源平台提交。

## 5. 站外重点平台

有实测数据支持的（主要来自新榜智汇 2025 年 12 月对豆包、元宝、DeepSeek、Kimi 的 142.9 万次问答、1683.6 万个信源网址的统计，GEO 服务商发布，观察性）[8]：

- **字节系内容**：今日头条、抖音——豆包用户侧高频引用 [8]。
- **微信公众号**：元宝用户侧约 10%，Kimi 也常引用 [8][15]。注意 mp.weixin.qq.com 的 robots.txt 对所有爬虫只放行首页等少数路径、其余全部 Disallow [13]，公众号文章基本只能被腾讯自家产品使用。
- **门户自媒体**：搜狐、网易（及今日头条）在四家 AI 中都有较高引用率 [8]。
- **百科**：百度百科是 DeepSeek 偏好信源，AI 会用百科类页面做交叉比对 [8]。
- **行业垂直媒体**：汽车类太平洋汽车网（约 11%，第一）、懂车帝、汽车之家、易车等进入前十；金融类雪球、新浪财经、和讯网等 [8]。

沿用原国内清单、但未找到可靠引用比例数据的平台（审计时照常检查，报告中不写引用占比）：

- 知乎（问答、专栏中的真实讨论与测评）。
- 小红书笔记、什么值得买（消费类）。小红书 robots.txt 对通用爬虫全部 Disallow，只对 Baiduspider、Sogou、YisouSpider、360Spider、bingbot 等放行首页、/explore 等少数路径 [13]。
- B 站（视频测评）。
- 百家号（百度内容平台）。有 GEO 服务商称百家号、百度百科是文心的核心信源 [16]，但属厂商自述、未经独立核实，只可作参考。
- "十大品牌"类榜单文章。

需要登录或受限的平台：微信公众号（站外搜索基本不可见）[13]；知乎、小红书、抖音等在未登录时可能出现登录墙或只显示部分内容，审计时以实际能否访问为准，查看不到的标"未能检测"。

几乎没有第三方提及 → P1，给出可执行的 PR / 测评 / 内容投放策略，不得建议刷评或伪造测评。

## 7. 本地化检查要点

- **ICP 备案**：《非经营性互联网信息服务备案管理办法》第十三条要求在网站主页底部中央标明备案编号，并在下方链接工业和信息化部备案管理系统网址 [11]。未展示 → P2，说明可能影响国内平台的信任和收录（推断）。
- **价格写法**：《明码标价和禁止价格欺诈规定》第九条要求标示价格"一般应当使用阿拉伯数字标明人民币金额"，第十三条要求网络销售"通过网络页面，以文字、图像等方式进行明码标价" [12]。写法如"¥1,299"或"1299 元"。检查价格是否为明文（不只在图片或整页长图里），有无标明交易条件对应的价格 [12]。
- **语言**：使用简体中文，且是本地化撰写而非英文站机翻；title / description 使用中文用户的问法。
- **日期与数字**：日期写成"2026年11月16日"或"2026-11-16"；更新日期写明文。
- **计量单位**：使用公制单位（千克、厘米、℃ 等），不只给英制。
- **电话**：大陆手机号 11 位、以 1 开头，国际写法为 +86 后接 11 位号码；固话为区号 + 号码，国际写法去掉区号前的 0 [14]。检查是否给出可拨打的本地客服电话。
- **地址**：按"省 / 市 / 区 / 街道 / 门牌"由大到小书写。
- **支付与配送**：说明支持的支付方式（如微信支付、支付宝）、发货地、配送时效、退换货政策。
- **权威出处**：国内用户与 AI 回答常见的可核实证据——国家标准号、检测报告、监管部门数据——应以明文出现在重点页上。
- **宣传语**：避免"行业领先""全网第一"等无依据说法，改为可核实的事实。

## 8. 证据适用性

本市场引用 `evidence.md` 的全部条目都属于**推断，证据较弱**。原因：

- E1–E16 的研究几乎全部基于英文 / 美国市场（ChatGPT、Perplexity、Google AI Overview、Gemini 等），没有一项直接测量豆包、千问、文心、DeepSeek、元宝或 Kimi。这里是按相同机制（先被检索、再被采纳）类推。
- 国内 AI 的检索来源大多不公开或只有厂商自述（如博查的 60% 说法、豆包搜索的宣传稿）[6][9]，无法像 E2 那样确认"引用页面 100% 来自自身检索结果"。
- 可参考的当地研究只有 GEO 服务商发布的观察性统计（新榜智汇）[8] 和 QuestMobile 的定性判断 [1]，没有同行评审的研究，也没有站内对比或受控实验。
- 相对可迁移的是 E13（引擎之间、语言之间引用来源重叠很低）：新榜数据显示国内各 AI 的信源生态明显不同 [8]，与 E13 的方向一致，但 E13 本身仍是在海外引擎上测得的。

报告中引用证据时写成"E2·强（国内为推断，证据较弱）"这类形式。
